# 安全、隐私与数据边界

RolePilot 面向本机或受控开发环境的个人练习。本文说明输入如何存储、哪些内容会发送到外部服务，以及把系统部署到更大范围前需要补充的安全能力。

## 凭据与身份

- 模型密钥和 Tavily 密钥只从环境变量读取。`.env` 被 `.gitignore` 忽略，公开仓库只保留不含真实密钥的 [`.env.example`](../.env.example)。
- 首次访问由服务端签发匿名 Bearer 凭据，并在服务端把凭据哈希映射到 owner。会话接口不接受客户端自带的 `owner` 查询参数或 `X-Owner-Id` 来改变身份。
- 浏览器按身份库的稳定数据环境标识保存 Bearer，活动会话、草稿和待确认回答进一步按匿名身份隔离。有效凭据复用原 owner；无法解析的凭据可为当前环境重新签发，但不会获得原 owner 的会话，也不会自动重发旧会话写请求。存储或网络故障不会触发身份替换。
- `/api/auth/context` 仅公开非秘密的环境标识；它及客户端保存的身份标识不能作为鉴权凭据。后端仍以 Bearer 的哈希映射决定访问权。
- Bearer 凭据相当于本地数据的访问能力。切回原数据环境且浏览器仍保存原凭据时可以恢复原会话；清除浏览器同源存储、切换 `localhost`/`127.0.0.1` 或更换端口后，浏览器可能无法再访问原会话。保留下来的旧凭据和草稿同样属于本地敏感数据，部署者应保护运行主机和浏览器环境。

## 输入、存储与删除

- 简历、JD、回答和报告保存在 `data/` 下的业务 SQLite；LangGraph 检查点使用独立 SQLite。运行期数据库、上传文件、OCR 语言数据和日志均不属于公开源代码。
- 上传原件只在解析阶段使用，成功或失败后都会尝试清理。删除会话会清理业务记录、回答缓存、调用台账、额度记录和对应检查点。
- 出口会过滤常见邮箱、电话和身份标记，默认关闭外部追踪；这只是常见模式的脱敏，不是完整匿名化，也不能保证模型服务端不留存输入。
- 为完成分析、出题、评估和报告，必要的简历、JD、回答文字会发送到 `.env` 中配置的模型服务；岗位调研会发送到 Tavily。云服务留存、训练和跨境策略由部署者按供应商条款确认。

## 模型与工具边界

- 当前客户端使用可配置的 OpenAI-compatible Chat Completions 和工具调用；JSON 输出经程序解析校验，未启用原生 `json_schema` 响应模式。密钥不会写入报告、公开健康检查或错误响应。
- Tavily 结果会标记来源和降级状态；搜索失败不会伪装成已联网。
- `CodeExplainer` 只生成解释，不执行用户代码；工具参数通过 Pydantic schema 和程序 allowlist 校验。工具轮数、批量大小和并发线程有上限。
- 上下文和整场 Token 预算在外部调用前预检，并在 SQLite 台账中预留；供应商没有返回有效 usage 时保留未知占额，不把未知写成零。该预算是程序保护，不是供应商账单硬上限。

## 部署边界

当前项目未声称提供：

- 互联网生产环境的 HTTPS 终止、企业 SSO、密码找回、细粒度 RBAC 或多租户隔离；
- 面向恶意用户的速率限制、配额售卖、内容审核和 DDoS/滥用防护；
- 跨业务 SQLite、LangGraph 检查点和外部模型调用的分布式原子事务；
- 对云端模型、Tavily、OCR 引擎或供应商日志的删除、审计和训练策略控制。

在公网运行前，应在反向代理配置 HTTPS 和限流，替换匿名身份方案，隔离数据库和上传目录，并根据所选模型/搜索供应商的条款评估个人信息处理。默认配置更适合本机、内网或受控演示环境。

## 使用建议

请在上传前移除不必要的身份证号、家庭住址、联系人和其他敏感信息；检查 OCR 文本后再开始面试；不要把真实密钥提交到仓库、日志或截图中。RolePilot 的评分只用于练习反馈，不应直接用于招聘、背景调查或能力认证。
